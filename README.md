### 🌳 Flagship — The Tree: Hierarchical Multi-Agent Orchestration System

A three-level agent hierarchy — one Grand Strategist (orchestrator), three domain Advisors
(architecture / implementation / verification), and tiered execution sub-agents routed by
cost-of-being-wrong across frontier and efficiency-class LLMs (Claude · Gemini · Grok · Hermes).
Nine governing laws: chain of command, plan-before-action with approval gates, independent
verification, halt-don't-guess escalation, two-strike tier escalation, step budgets, and a
files-are-truth audit trail. Built on **Model Context Protocol (MCP)** with structured JSON-schema
tool calling; every mutation git-checkpointed. Packaged as a reusable skill with export packs for
Claude Desktop and the Hermes agent ecosystem.
